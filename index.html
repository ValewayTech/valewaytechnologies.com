Where Agents Converge

A trust layer for personal AI agents.

Personal agents are starting to act on our behalf. Valeway is independent research into how they can do so safely, with permissions checked in code before an agent acts, and only what code can't decide escalated. The aim is simple: agents that people, businesses and public services can rely on when they work together.

What we're working on

  • Rules enforced in codeResearching permissions that are checked in code before an agent acts.
  • Safe agent-to-agent exchangeWays for agents acting for different people and organisations to work together without overreaching.
  • Open, testable researchMethods and findings published so others can examine and build on them.
